# BESTIE 3D Pet Assets — V3

The included cat GLB assets in this prototype are **procedurally generated in the working environment** for integration/testing of the BESTIE 3D renderer. They are not copied from a third-party model library.

They are real GLB meshes with separate 3D geometry for the animal and outfit variants. They are intended as an integration/prototype asset set; they are **not claimed to be photorealistic production character models**.

For the final commercial/store release, replace these prototype meshes with a professionally authored, rigged, textured cat model and fitted clothing meshes, and preserve the same asset paths so the renderer does not need architectural changes.
